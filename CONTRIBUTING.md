# Contributing to M5Loki

Thanks for your interest in improving M5Loki.

## Good contributions

- Bug fixes
- M5StickC Plus2 compatibility fixes
- Better Arabic rendering
- Smaller/faster firmware
- New semantic reactions or special actions
- UI improvements that remain readable on the 240×135 display
- Documentation and setup improvements

## Before opening a pull request

1. Do not include API keys, Wi-Fi passwords, or other secrets.
2. Test that the firmware compiles for the M5StickC Plus2.
3. Keep the UI lightweight and responsive.
4. Preserve English and Arabic behavior unless the change intentionally improves it.
5. Describe what changed and how you tested it.

## Style

M5Loki is designed to feel minimal, cute, and fast. Prefer simple embedded-friendly solutions over heavy dependencies.
